# VLOO Space Object Page Prototype

Standalone design prototype for the VLOO customer-facing space object page.

## [Open the interactive prototype](https://andreas-nbs.github.io/vloo-space-object-page-prototype/)

Use the live prototype link above to test the interactions. The GitHub file and
code preview is not interactive.

The three space images under **The atmosphere**, **The space**, and **Your
hosts** can be clicked to open the full-screen image gallery. The gallery also
supports previous/next buttons, arrow keys, and Escape to close.

All required images are included in this repository; no build step or external
dependencies are needed.
